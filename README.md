# Omni Beauty Reno — website

Static site (no build step). Deploy: push this folder to GitHub, import in Vercel (Framework: Other, root = this folder).

- `index.html` — whole site (CSS + JS inline)
- `assets/video/omni-reel.mp4` — 67s muted brand loop (3 clips + OMNI intro/outro), 540x960
- `assets/img/` — optimized photos (webp), gold/cream logo PNGs, favicon

Booking links point to Vagaro (vagaro.com/us02/omni and /omni/services).
